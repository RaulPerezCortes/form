Constructor de formularios

Crea formularios libres o conserva la pregunta con botón que huye. Todo se previsualiza al instante.

Solo se aceptan enlaces cifrados generados por este constructor.

Campos del formulario

Puedes reordenar con ↑ ↓. Los campos de opciones usan una opción por línea.

Abrir

El enlace usa compresión y ofuscado. Una URL corta universal para formularios muy grandes requeriría un servidor o servicio de enlaces que guarde el formulario.
